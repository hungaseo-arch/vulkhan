# 2026-10-21 — 고객 지점(kota)·영업담당(sales) 표기 통일

> **사용자가 Neon 콘솔에서 실행합니다.** 앱 배포와 별개이며 순서대로 하나씩 실행하세요.

## 배경

`pelanggan.kota` 에 `Semarang` / `SEMARANG` 처럼 같은 지점이 다른 철자로 들어 있어
지점별 집계와 삭제 기안 카드 표시가 갈라졌습니다 (VK-WEB-2026-1021-02 A-2).
`sales` 도 대소문자·공백 차이로 같은 담당자가 여러 줄로 잡힐 수 있습니다.

이번 배포부터 고객 등록/수정 화면은 지점·담당자를 **목록에서 선택**하고,
서버(`POST/PUT /api/pelanggan`)가 앞뒤 공백 제거·연속 공백 1칸·대문자로 저장합니다.
이 마이그레이션은 **기존 행**을 같은 규칙으로 맞춥니다.

## 순서

| 파일 | 내용 | 변경 |
|---|---|---|
| `00_cek.sql` | 현재 kota / sales 값별 고객 수 | 없음 |
| `10_dry_run.sql` | 바뀔 행 미리 보기 (현재값 → 새값) | 없음 |
| `20_update.sql` | 트랜잭션 안에서 UPDATE 후 재확인 | **있음** |

예상: kota 는 소문자 섞인 행(약 6건, 예: `Semarang`)이 대문자로 바뀝니다.
sales 는 `10_dry_run.sql` 2번 결과만큼 바뀝니다.

## 하지 않는 것

- **빈 값은 채우지 않습니다.** 지점·담당자가 비어 있는 고객은 그대로 둡니다.
- **다른 이름끼리 합치지 않습니다.** `PUTRA` → `PUTRA LUBIS` 같은 병합은 동일 인물인지
  확인이 필요하므로 `20_update.sql` 끝에 주석으로만 두었습니다. 확인 후 주석을 풀어 실행하세요.
- `SMG` / `SEMARANG` 같은 별칭은 앱이 같은 지점으로 인식하므로 이번에 고치지 않습니다.
